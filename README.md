**Day 1 Task**
**Objective**
//
Build an E-Commerce backend application using Python with the following services:
Products Service
Catalog Service
Cart Service
Shipping Service

**Technologies Used**
Python
Pandas
NumPy
CSV Files (for data storage)
Scope
No frontend/UI
Backend logic implemented using Python modules
Data stored and managed through CSV files
Modular service-based design
Extended Features Added

The initial task was further enhanced by introducing a User Management Module and additional e-commerce functionalities.

**User Module
**
Users can:

Register as a new user
Login using credentials
View personal profile information
Access previously saved cart information
Place orders
View order history
Track shipment status of orders
Features
Product Management
View all available products
Manage product information
Store products in CSV files
Catalog Service
Browse products
Search products by category
Search products by product name
Cart Service
Add products to cart
View cart contents
Calculate total cart value
Checkout Service
Purchase products from cart
Generate customer orders
Store order details
Order Management
View previously placed orders
Maintain customer order history
Shipping Service
Track shipment details
View shipment status
Access shipping policy information
Analytics Module

Implemented using Pandas and NumPy.

Includes:

Product Price Analysis
Stock Analysis
Category Distribution Analysis
Shipment Trend Analysis
